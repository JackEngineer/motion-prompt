# 提示词 2：制作自己领域的术语库

适用于能够读取本仓库的 Claude Code、Codex、Cursor 等编程 AI。替换 `<FIELD>`、`<LANGUAGE>`、`<slug>` 和 `<lang>`。

领域不必是视频。例如布光、声音设计与混音、UI 动画、图表类型、字体排印、摄影、烹饪技法、建筑细部、舞蹈动作、编织针法。

```text
阅读 make-your-own/README.zh-Hans.md、make-your-own/render.mjs 和两套中文模板。
  make-your-own/examples/camera-moves/zh-Hans/index.html      浅灰、单一蓝色、图示风格
  make-your-own/examples/motion-graphics/zh-Hans/index.html   深海军蓝卡片、四种颜色
每套把一个领域的 24 个术语制作成三个循环视频，每个视频八张动态卡片。
两套示例的风格刻意不同。共同规则是：名称是主体，每张卡片展示该名称的含义。

目标：用 <LANGUAGE> 为“<FIELD>”制作同类术语库，保存为
make-your-own/examples/<slug>/<lang>/index.html。

第 1 步：选择术语，然后停下来向我展示列表
- 选出 24 个术语，分为三组，每组八项并有简短标题。
  如果该领域实际上更少或更多，说明原因，并提出能填满每页八项的数量。
- 使用 <LANGUAGE> 从业者真实使用的名称，输入 AI 提示词或搜索框应得到正确内容。
- 逐项核实，可以联网时搜索。说明参考的是教科书、手册、术语表还是行业网站。
  不自造名称，不生硬直译；当地通常保留英文时就保留英文。标明所有不确定项。
- 每组由基础到进阶排序，避免两个术语的示例看起来相同。
- 每项写出英文名称（目标语言非英文时）、一句话释义、一句按名称向 AI 提需求的例子，
  以及一句卡片将展示什么的说明。
- 等我确认后再写代码。

第 2 步：与我确定视觉风格
- 视觉风格由我们决定。询问我是否有想采用的颜色、字体或参考。
  如果没有，用各一句话提出两个方向，让我选择。不要默认照搬示例风格。
- 无论选择哪种风格，24 张卡片统一调色板和字体，卡片下方的名称必须最容易阅读。

第 3 步：实现
无论视觉风格如何，都遵守这些术语库规则。
- 每张卡片是一段展示效果本身的小动画；隐藏标签时，也能辨认是哪个术语。
  一张卡片表达一个概念，不用效果图标代替效果演示。
- 非视觉领域，如声音、烹饪或写作，应展示变化：波形、剖面、前后对比或步骤顺序。
- 手机可读。Canvas 1200x1350，30fps，每页八张卡片，一页对应一个视频。
  卡片下方为编号与名称（约 36px、粗体），第二行较小（约 22px）。
  手机显示视频约为原尺寸的三分之一，因此不要再减小字号，保持足够文字对比。
- 同页卡片共用周期长度。示例为 4.7s，播放两次共 9.4s，页面循环无跳变。
  末帧必须自然衔接首帧；在周期内通过缓动返回或交叉淡化回到初始状态。
- 独立重复的内容，如闪烁或加载旋转，在整页时长内必须完成整数次重复，否则循环有接缝。
- 不闪屏，不快速切换大面积明暗。仅当硬切本身是卡片主题时才使用硬切。
- 给观众看清的时间：初态停留约 0.5s，再运动，随后停留在终态。
- 每帧必须是帧编号的纯函数。不使用 Date、performance.now、无固定种子的 Math.random
  或 CSS 动画。保留 render.mjs 使用的接口：window.N_FRAMES、window.renderFrame(i)、
  window.READY、?page=N、?render=1。
- 不从网络加载资源。使用本机安装字体并告诉我字体名。所有内容通过代码绘制，
  不使用属于他人的照片、标志或角色。
- 可复制任一示例的页面框架和渲染接口作为起点。
  示例辅助函数与主题有关，例如 3D 镜头的 cam、proj、world、person；
  删除不用的部分，为当前领域编写适合的小型辅助函数。

第 4 步：交付前自行检查
- 渲染视频和帧预览图：
    cd make-your-own && node render.mjs examples/<slug>/<lang>/index.html --all --sheet
- 打开 out/ 内每张帧预览图，逐项检查：隐藏标签后，是否仍能辨认这个术语？修复不合格项。
- 同时检查文字无截断、无重叠，每个 mp4 首尾画面衔接。
  ffprobe 应显示 1200x1350、30fps、h264、yuv420p、9.4s。
- 交付表格列出 24 项的编号、名称、英文名、释义、示例需求和核对来源，
  另列不确定项、所用字体和文件位置。
```

完成后如需把领域加入资料库，请参阅[贡献指南](../../../CONTRIBUTING.zh-Hans.md)。
