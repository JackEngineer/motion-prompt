用术语和示例建立共同语言

这里收录了创作者发布的术语、动态示例和速查表，涉及不同领域、语言与风格。我们选择由投稿者自行制作示例的帖子，帖子内容及相关权利属于各位作者。

被收录不代表作者为本站背书。案例介绍由本站撰写。

关于嵌入内容

本页通过 X（原 Twitter）嵌入展示帖子。打开后将从 X 服务器加载内容并使用 X Cookie。X 可能记录浏览情况并将其用于广告。嵌入时已设置 dnt，请求 X 不将此次访问用于个性化推荐。
